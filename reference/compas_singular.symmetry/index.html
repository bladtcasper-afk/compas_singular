    symmetry¤

    Symmetry for either route: find the symmetry of a domain, mesh one unit, and expand it by the group.

    Classes¤

    SymmetryReport ¤

    SymmetryReport(
    domain: Domain,
    group: SymmetryGroup,
    tol: float,
    near: float,
    include: Sequence[str],
    deviations: dict[str, tuple[float, Any]],
    near_misses: list[tuple[str, float, Any]],
    circle_like: bool,
    max_order: int,
)

    The detected symmetry of a domain.

    Attributes:

    • group (.group.SymmetryGroup) –

      The largest group whose every element passed.

    • centre ([x, y, z]) –
    • keys (list[str]) –

      The names a script picks a unit by -- R90, M45 ...

    • deviations (dict) –

      key -> (worst distance, (tag, point)) for every element of group. How far from exact the drawing is.

    • near_misses (list) –

      (key, worst distance, (tag, point)) for elements that did NOT pass but came within the near-miss limit -- almost always a drawing slightly off, and the tag says which curve.

    • tol, near (float) –
    • circle_like (bool) –

      Every tested rotation passed: the domain is (sampled from) a circle, and the reported order is only the highest one tested.

    • domain (.domain.Domain) –

    find_symmetry ¤

    find_symmetry(
    outer: Sequence[Any] | None = None,
    inners: Sequence[Sequence[Any]] | None = None,
    guides: Sequence[Sequence[Any]] | None = None,
    poles: Sequence[Sequence[float]] | None = None,
    tol: float | None = None,
    include: Sequence[str] = INCLUDE,
    max_order: int = 12,
    near: float | None = None,
    centre: Sequence[float] | None = None,
    domain: Domain | None = None,
) -> SymmetryReport

    Detect the rotations and mirrors that map the input onto itself.

    Parameters:

    • outer (Sequence[Any] | None, default: None ) –

      The domain. Or pass domain (a Domain) instead.

    • inners (Sequence[Any] | None, default: None ) –

      The domain. Or pass domain (a Domain) instead.

    • guides (Sequence[Any] | None, default: None ) –

      The domain. Or pass domain (a Domain) instead.

    • poles (Sequence[Any] | None, default: None ) –

      The domain. Or pass domain (a Domain) instead.

    • tol (float, default: None ) –

      Drawing precision: the largest distance at which an image still counts as landing on the input. Default 1e-4 times the bounding-box diagonal.

    • include (sequence of {'walls', 'holes', 'guides', 'poles'}, default: INCLUDE ) –

      What must be symmetric. Leave out 'guides' to get the symmetry of the plate regardless of an off-centre cable.

    • max_order (int, default: 12 ) –

      Highest rotation order tested.

    • near (float, default: None ) –

      Deviations up to this are reported as near-misses. Default 1e-2 times the diagonal.

    • centre ([x, y, z], default: None ) –

      Override the area centroid.

    Returns:

    • SymmetryReport –
